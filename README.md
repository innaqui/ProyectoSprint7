# Análisis interactivo de anuncios de vehículos

Esta aplicación web fue creada con Streamlit y permite explorar un conjunto de datos con anuncios de venta de coches en Estados Unidos.

## ¿Qué se puede hacer con esta app?

- Ver un **histograma** del odómetro (cuántos kilómetros/millas ha recorrido cada coche).
- Ver un **gráfico de dispersión** que compara el odómetro con el precio de los coches.

## Herramientas usadas

- Python
- Pandas
- Plotly Express
- Streamlit
